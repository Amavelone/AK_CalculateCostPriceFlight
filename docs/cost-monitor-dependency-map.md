Статус: схема отражает подтвержденные связи из M-кода Power Query, Query Tables и Excel-формул. Пунктиром отмечены неиспользуемые/проблемные ветки.

```mermaid
    cbr["CBR XML: USD"]

    tariffQuery["Power Query: ЦРТ_Check"]
    manualTariff[("ЦРТ_pls: ручные тарифы")]
    tariffTable[("ЦРТ_Check: тарифы")]

    registryQuery["Power Query: Реестр"]
    fuelTable[("РеестрКер: цена по АП")]
    detailQuery["Power Query: Выгрузка 1С"]

    routes[("ИШР: маршрут и налет")]
    refs[("Справочники и Прочее")]
    intl[("Признак МВЛ")]
    ground["НО: услуги по плечам"]

    srv -->|"Читает"| tariffQuery
    manualTariff -->|"Добавляет"| tariffQuery

    tariffTable -->|"Ищет ставки"| ground

    reg -->|"Читает"| registryQuery
    cbr -->|"Курс USD"| registryQuery

    reg -.->|"Очищает"| detailQuery
    detailQuery -.-> detailTable

    routes -->|"Налет и топливо"| calc
    intl -->|"МВЛ или ВВЛ"| calc
    refs -->|"Коэффициенты и нормы"| ground
    refs -->|"Сценарии ЛЧ"| calc
    calc -->|"Плечо и объемы"| ground
    ground -->|"ГСМ и НО"| calc
    calc ==> result

```

## Целевой веб-поток

```mermaid
flowchart LR
    settings["Параметры источников\nпуть, маска, парсер"]
    sources["Экран Источники\nзагрузка, просмотр, обновление"]
    files[("Файлы в настроенных директориях")]
    parse["Парсинг и снимок данных"]
    sourceView["Просмотр исходных и\nраспарсенных данных"]

    imported[("Импортированные тарифы\nс версией файла")]
    manual["Подключённые услуги\nручное добавление"]
    tariffs[("Единый справочник ЦРТ\nпризнак: файл / вручную")]

    legs["Главная страница\nпроизвольное число плеч"]
    controls["Сценарий, ГСМ, техстоп,\nбортпитание"]
    engine["Расчет себестоимости\nпо каждому плечу"]
    detail["Детализация компонентов\nможно скрыть"]
    total["ИТОГО М1 / М2 / М3"]

    settings --> sources
    sources -->|"сохраняет файл"| files
    files -->|"обновить"| parse
    sources --> sourceView
    parse --> sourceView
    parse --> imported
    imported --> tariffs
    manual -->|"сохраняется между обновлениями"| tariffs

    legs --> engine
    controls --> engine
    tariffs --> engine
    engine --> detail
    engine ==> total
```

Здесь «единый справочник ЦРТ» — представление распарсенных и ручных строк, а не отдельный лист `ЦРТ+`. При совпадении ключа ручная строка сохраняется и помечается конфликтом; в режиме совместимости расчет выбирает импортированную строку, поскольку она стоит первой.

## Подтвержденные особенности

- M-код Power Query — эталон преобразований для текущего переноса. Его поведение и порядок результатов воспроизводятся без новых интерпретаций.
- `ЦРТ_pls` добавляется в конец результирующего набора. По утвержденному назначению таблица содержит только отсутствующие в выгрузках услуги/аэропорты и не используется как override.
- `Выгрузка_1С` загружается как почти исходная распарсенная детализация керосина для анализа; прямых ссылок на нее в формулах расчета нет.
- Вспомогательные запросы `Запрос1` и `fnGetCurrencyRate` не загружаются в лист и не вызываются активными запросами.
- `ЦРТ_МВЛ` не включен в расчетный путь и содержит 240 сохраненных ошибок `#REF!`.

Для программной реализации используйте [business-logic baseline](cost-monitor-business-logic.md) и [архитектурный и UX-план](cost-monitor-architecture-plan.md).
